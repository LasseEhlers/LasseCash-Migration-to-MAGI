# LasseCash brand & history archive

Recovered 2026-08-28 from public sources, for the record. Nothing here is
used by the site or the contract; it exists so the history of LasseCash
(launched June 2019 on Steem-Engine, moved to Hive-Engine April 2020, migrated to MAGI 31 Aug 2026) can be shown
one day. Every file lists where it came from. Small files live in this
folder; the full set (110 MB, including the original-resolution scans and
every `NFTLC` series by @lasseehlers, @zaxan and @doze) is attached to the GitHub Release
**`history-archive-2026-08-28`** on this repository.

## How the NFTs were found

Hive-Engine `nft` contract, symbol **`NFTLC`** (issuer `nftlassecash`) —
the old lassecash.com's own NFT platform, 34 series / 76 editions, queried
with `{"method":"find","params":{"contract":"nft","table":"NFTLCinstances"}}`.
19 series carry their IPFS CID on-chain; the rest are referenced only by
Tribaldex's OpenHive marketplace (`tribaldex.com/openhive/NFTLC/…`), whose
CDN (`cdn.tribaldex.com/marketplace/lassecash/<CID>.<ext>`) still served
every file. @lasseehlers never minted on NFTShowroom. Full per-file
provenance: `manifest.md` inside the zip.
