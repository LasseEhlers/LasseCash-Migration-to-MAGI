# Found something wrong? Tell me here.

*Draft for Lasse. Pin this post, or link it from `/about` and the video
descriptions next to `/check`.*

---

LasseCash on MAGI is immutable after launch — no admin key, no quiet
patches, a real hardfork if something is ever seriously wrong. That only
means something if people can actually tell me when something looks off.

**Reply to this post if:**
- a number on the site looks wrong
- a claim, mint, vote, or swap didn't do what you expected
- something is confusing and you're not sure if it's a bug or you

Include your account name and what you did, if you can. Screenshots help.
I read every reply here myself.

**If you're technical** and want to file something more formal — a
reproducible bug, a suspected contract issue — use GitHub Issues on the
repo instead: https://github.com/LasseEhlers/LasseCash-Migration-to-MAGI/issues.
It's public, permanent, and I can track it against what's actually fixed
and when.

**What I can't do:** change the contract after day 40 (the keys are
burned by then, on purpose — see `/about`). Before that, a fix is a
public, timelocked code update, announced before it goes live, never
silent. After that, a real bug means a real hardfork, not a quiet patch —
so the sooner something is reported, the more options there are.

This post stays open. Nothing here expires.
